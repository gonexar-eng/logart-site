# Лог-Арт — сайт транспортной компании

Многостраничный сайт транспортной компании «Лог-Арт» (Пятигорск). Чистый HTML/CSS/JS без сборки.

## Структура
- `index.html` — главная
- `uslugi.html` — услуги
- `avtopark.html` — автопарк
- `o-kompanii.html` — о компании, география, частые вопросы
- `kontakty.html` — контакты, карта и форма заявки
- `styles.css` — стили (фирменные цвета: красный `#e31e24`, серый, чёрный)
- `script.js` — меню, форма заявки (отправляет заявку в WhatsApp)
- `assets/` — логотип

## Что заменить перед запуском
Всё, что помечено `TODO`. Шапка и подвал повторяются на каждой странице, поэтому меняйте их во всех файлах:
- телефон `+7 (900) 000-00-00` во всех `.html` и `WHATSAPP_PHONE`, `TELEGRAM_USER` в `script.js`
- цифры на главной («24/7», «от 1 часа»)
- текст «О компании»
- почту, адрес и режим работы в блоке «Контакты»
- автопарк (реальные машины и фото)
- координаты на карте (`ll=` в iframe Яндекс.Карт)

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → Deploy from branch → `main`).
